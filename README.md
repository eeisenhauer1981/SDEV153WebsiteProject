This website is meant to help home cooks organize their recipe collections. Users can save links to recipes from any website. Then, enter a number of breakfasts, lunches, and dinners on the create menu page to randomly select a menu from the recipe collection.
From the home page: visit any of the four function pages in the site.
-->View Current Menu: After a user generates a menu plan, the selected recipes are listed on the View Current Menu page, organized by meal type. On mobile view, meal categories are collapsed, and users can tap the category title to expand the list. On desktop, all current menu recipes are displayed. Tapping/clicking on a recipe card launches the recipe's home webpage in a new tab.
-->Create New Menu: Users can enter a number of breakfasts, lunches, and dinners, then click Create Menu button. This deletes the previous menu and generates a new one. A summary list of the menu recipes is displayed, and when the user visits the View Current Menu page, the new menu is displayed.
-->View All Recipes: Users can see a list of all saved recipes, organized by meal category. On mobile view, meal categories are collapsed, and users can tap the category title to expand the list. On desktop, all current menu recipes are displayed. Tapping/clicking on a recipe card launches the recipe's home webpage in a new tab.
-->Add New Recipe: Users complete the form including recipe name, recipe link, recipe category and an optional link to a photo on the recipe's home website. This adds a new recipe to the collection, making it available to view from the View All Recipes page and it can be included in future menus.

For demo purposes, the site launches with six "starter" recipes to review functionality. You can add new recipes to this starter pack to grow the recipe collection.
Recipes and menus are saved using localStorage. This means that collections are device-specific. If you use the website on your computer and a mobile device, recipe collections and menus will differ on each device.
